# NEON TETRIS

Неоновый тетрис в браузере: чистый JavaScript, без зависимостей и без сборки.
Готов к деплою на Vercel — играется по ссылке.

![стек](https://img.shields.io/badge/stack-vanilla%20JS-a855f7) ![deps](https://img.shields.io/badge/dependencies-0-22d3ee) ![license](https://img.shields.io/badge/license-MIT-64748b)

## Возможности

- Полноценная механика по **Tetris Guideline**: SRS-поворот с кик-оффсетами (включая отдельную таблицу для I), генератор **7-bag**, **hold**, очередь из 5 фигур, **ghost-подсказка**.
- **Lock delay** 500 мс (до 15 сбросов), гравитация по уровню, soft drop (×20) и hard drop (×2 за клетку).
- Очки: одиночные / двойные / тройные / тетрис, **T-spin**, **back-to-back**, **комбо**, уровень каждые 10 линий.
- Неоновый рендер на canvas: свечение блоков, анимация очистки линий, красная пульсация при опасной высоте стека.
- Управление с клавиатуры (DAS/ARR-авто-повтор) **и** с тач-экрана (экранные кнопки + свайпы по полю).
- Рекорд сохраняется в `localStorage`.
- Адаптивная вёрстка: десктоп (три колонки) и мобильные (поле + кнопки).

## Управление

| Действие | Клавиши |
| --- | --- |
| Сдвиг влево / вправо | `←` `→` |
| Поворот по часовой / против | `↑` / `X` — `Z` |
| Мягкий сброс | `↓` |
| Мгновенный сброс | `Space` |
| Отложить фигуру | `C` / `Shift` |
| Пауза | `P` / `Esc` |
| Начать заново | `R` |
| Старт / продолжить | `Enter` |

На телефоне: кнопки под полем (свайп влево/вправо — сдвиг, свайп вниз — сброс, тап — поворот).

## Локальный запуск

```bash
npm run dev     # http://localhost:3000
npm test        # юнит-тесты игрового ядра
```

Зависимостей нет — `npm install` не требуется.

## Структура

```
index.html            разметка страницы
src/styles.css        тема и адаптив
src/js/pieces.js      фигуры, SRS-кики, 7-bag
src/js/engine.js      игровая логика (без DOM)
src/js/renderer.js    отрисовка canvas
src/js/input.js       клавиатура + тач
src/js/storage.js     рекорд в localStorage
src/js/main.js        игровой цикл и интерфейс
server.mjs            статический dev-сервер (node, без зависимостей)
tests/                юнит-тесты (node:test)
```

## Деплой на Vercel

Проект статический, поэтому сборка не нужна — Vercel отдаёт файлы как есть.

```bash
npm i -g vercel
vercel            # preview
vercel --prod     # production + продакшен-домен
```

Или подключите репозиторий на [vercel.com/new](https://vercel.com/new):
Framework Preset → **Other**, Build Command — оставить пустым, Output Directory — `/`.

При каждом пуше в ветку `main` Vercel пересобирает деплой автоматически.
